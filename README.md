# 손끝 원장

사라지는 숙련자의 손끝 노하우(암묵지)를 장부로 남겨, 신입이 쓰게 하는 서비스입니다.
한국디지털산업학회 2026 추계 대학(원)생 아이디어 공모전 출품작이며, 웹 서비스와 Unity 3D 훈련 시뮬레이션으로 이루어져 있습니다.

- 웹: https://sonkkeut-ledger.vercel.app

## 주제

제조 현장의 숙련자가 퇴직하면 작업표준서에 없는 요령(원료 습기 확인, 금형 온도 기다리기, 체크링 마모 점검 등)도 함께 사라집니다. 신입은 불량이 나도 원인을 모른 채 조건을 건드리게 됩니다.

**이야기: 김민준 씨의 하룻밤.** 입사 4주차 신입 김민준 씨가 박 조장 없이 야간 교대로 도어 트림 100쇼트를 사출합니다. 하얀 물결 같은 불량이 생기는데 인수인계에는 특이사항이 없었습니다.

## 서비스가 하는 일

1. **조각으로 남기기**: 숙련자의 노하우를 증상, 원인, 해야 할 일, 출처(누가, 몇 년차)가 붙은 조각(TF-001 등)으로 장부에 쌓습니다.
2. **현장 에이전트**: 신입이 본 대로 적으면("하얀 물결 같은 게 생겨요") 해당하는 조각을 찾아 줍니다. 용어를 몰라도 됩니다.
3. **노하우 남기기**: 조장이 퇴근 전 노하우를 장부에 남깁니다. 조각이 쓰일 때마다 원작성자에게 보상 근거가 쌓입니다.

체험에서는 같은 조건에서 "작업표준서만 보면"과 "숙련자 조각을 따르면"의 불량률을 비교합니다. 수치는 모두 **예시 가정 모델**입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `agent-web/` | 웹 랜딩 페이지와 체험(인터뷰 에이전트, 작업 도우미, 보상 원장). 정적 HTML/CSS/JS |
| `unity-training/` | Unity 3D 사출 공장 훈련 시뮬레이션 (Unity 6000.6.9f1, 코드로 장면 구성) |
| `docs/` | 문서 |

## Plant Simulation으로 만들기

같은 시나리오를 Siemens Tecnomatix Plant Simulation으로 구축하기 위한 명세가 있습니다.
공정 객체, 입력값, 불량률·다운타임 계산식, 조각 5개, 검증용 기준값을 담았습니다.

→ [docs/PLANT_SIMULATION.md](docs/PLANT_SIMULATION.md)

## 실행

웹 (로컬): 정적 파일이라 아무 정적 서버로 열면 됩니다.

```
npx serve agent-web
```

Unity: Unity 6000.6.9f1로 `unity-training/`을 열고 메뉴 `암묵지 훈련`에서 장면을 만들거나 빌드합니다.
명령줄 빌드는 `unity-training/Assets/Editor/BuildTools.cs` 상단 주석을 참고하세요.

## 사용한 외부 자료

- 캐릭터와 동작: Quaternius Universal Base Characters, Universal Animation Library (CC0)
- 기사와 통계 출처는 웹 페이지의 "근거·참고문헌" 창에 모아 두었습니다.
